# 온라인 의류 쇼핑 상담 AI Agent

## 설계
요청 -> llm 생각 -> Tool 설정 -> llm 응답 답변 생성 -> 요청 응답

쇼핑 상담 AI Agent 의도: 3544, 4050 여성들의 온라인 쇼핑에서 불편함을 덜어주기 위함. 
불편함 예시: 3544, 4050 여성들은 앱 사용시 글자가 잘 보이지 않는다는 단점, 앱 내 기능 찾기 어렵다는 점, 출산 등으로 인한 체형 변화로 인한 핏 체크가 어렵다는 점

이 문제에 대한 해결점: 쇼핑 AI Agent를 넣어서 쇼핑 과정의 불편함을 줄여준다.

Agent대답 위한 데이터: FAQ 크롤링, 퀸잇 여성 상위 3개 제품에 대한 리뷰 크롤링

데이터 선정 방식: 3544, 4050 여성들이 주로 사용하는 쇼핑 웹 사이트 선정(posty,퀸잇)
웹이나 앱에 대한 리뷰를 찾으려고 시도 
-> 이유: 웹이나 앱 사용중에 나타나는 어려움에 대한 리뷰를 통해 쇼핑 과정 중 어려움으로 연결 지을 수 있을 것 같아서
-> 데이터 수집 실패: 앱이나 웹 자체에 대한 리뷰 수 부족, 쇼핑 과정 중의 어려움이 아닌 앱이나 웹 자체에 대한 불만사항 (ex.앱이 자꾸 튕겨요)

FAQ에서 데이터 얻으려고 시도
-> 이유: FAQ는 자주 올라오는 질문을 모아두는 곳, FAQ에서 로그인 방식, 주문 언제오는지 등 쇼핑 할 때 겪는 문제에 대해 자주 올라오는 의문점을 올리는 곳으로 쇼핑 과정 중에 생기는 의문점을 쇼핑 과정 중 겪는 어려움으로 연결지을 수 있을 것 같아서 데이터를 얻어보려고 했다.
-> posty 사이트에서 FAQ에 대한 데이터를 크롤링하여 데이터 수집
-> FAQ에 올라온 “카테고리/섹션별로” FAQ를 크롤링해서 faq.db에 저장 
-> 카테고리 분류 이유: 주문,배송 관련 질문과 상품,문의 관련 질문 등 카테고리별 질문이 존재하고 카테고리 별로 데이터에 저장하면 질문이 들어왔을 때 키워드를 이용해서 질문에 대한 답변을 빠르게 찾을 수 있을 것 같아 카테고리 분류

여성 상위 3개 제품에 대한 리뷰 크롤링
-> 이유: 모든 카테고리, 모든 제품에 대해 크롤링한 데이터는 그 수가 많아 vectorDB를 이용하여 저장을 해야 할 것 같아서 작은 리뷰 데이터를 이용하기로 결정
-> 퀸잇 사이트에서 여성 셔츠에 대해 상위 3개 제품에 대해 데이터를 수집
-> 리뷰 데이터는 리뷰 문장 속 키워드를 기반으로 사이즈감, 기장감, 소재감을 분류함 
-> 예시: "길어요", "길게", "기장이 길" → 길어요 / "시원", "얇", "가벼", "여름" → 시원함/가벼움
-> 키워드 별로 사이즈, 기장, 소개 분류 이유: 먼저 키워드 별로 카테고리를 분류했을 때 FAQ와 마찬가지로 문장 전체에 대해서 저장된 데이터를 참고하는 것 보다 키워드를 이용해 저장한 데이터를 참고하는 것이 더 빠르게 걸릴 것 같아 키워드를 카테고리별로 분류

설계
요청 -> llm 생각 -> Tool 설정 -> llm 응답 답변 생성 -> 요청 응답
요청을 보냈을 때 질문에 대해서 llm이 질문 종류를 분류하도록 함. 주문,배송등 자주 나오는 질문에 대한 요청인지, 핏 체크 등 옷 자체에 대한 질문인지 분류
질문의 유형을 분류하여 질문에 맞는 tool을 선정. FAQ관련 대답은 FAQ에서 크롤링해 모은 데이터를 이용해 대답을 생성
옷 핏과 관련된 대답은 퀸잇의 리뷰 데이터를 참고하여 응답 생성

세부 파이프라인: 요청 -> llm 질문 분류 -> FAQ tool, 상품 목록, 상품 추천, 셔츠/상의/여름옷 등 상품 자체를 묻는 질문 tool, 후기, 리뷰, 핏, 사이즈감, 소재, 비침, 두께, 기장, 팔뚝, 어깨 등 착용 후기 tool 호출
-> 질문에 맞는 tool을 이용, llm 응답 생성 -> 답변 프론트에 반환

파이프라인 설계 근거: 간단한 AI Agent만들 의도로 AI Agent에 대한 파이프라인을 복잡하게 구성하지 않음.

질문: 저는 키 160cm, 몸무게 50kg이고 여름 셔츠를 아방방하고 입고싶은데 어떤 사이즈가 좋을까요?
현재 대답: 여름 셔츠를 아방방하게 입고 싶으시다면, 다음 두 가지 제품을 추천드립니다.

1. **여성 루즈핏 칠부소매 남방 셔츠** (오아즈)
   - **사이즈**: 정사이즈로 구매한 리뷰가 많습니다. 160cm, 52kg의 고객이 이 셔츠를 정사이즈로 착용했으며, 어깨너비가 딱 맞고 전체 길이도 적당하다고 평가했습니다.
   - **핏**: 루즈핏으로 되어 있어 여유로운 느낌을 줍니다.
   - **소재**: 시원하고 가벼운 느낌으로 여름에 적합합니다.
   - **기장**: 적당한 길이로, 다양한 하의와 잘 어울릴 것 같습니다.
   - **비침 여부**: 리뷰에서는 비침에 대한 언급이 없으므로, 일반적인 여름 셔츠로 생각하시면 될 것 같습니다.
   - [상품 링크](https://web.queenit.kr/product/e0c375d44b160cf299fa96aa260664ac)

2. **[~88까지]바주 포켓 패치 포인트 셔츠** (퀸이즈)
   - **사이즈**: 160cm, 54kg의 고객이 정사이즈로 착용했으며, 사이즈가 적당하다고 평가했습니다.
   - **핏**: 여유로운 핏으로, 아방방한 느낌을 줄 수 있습니다.
   - **소재**: 시원한 질감으로 여름에 적합합니다.
   - **기장**: 전체 길이가 적당하다고 리뷰에서 언급되었습니다.
   - [상품 링크](https://web.queenit.kr/product/346551f70d8cba500920c2605f756fba)

이 두 제품 모두 여름에 시원하게 입기 좋은 셔츠입니다. 키와 몸무게가 비슷한 리뷰를 참고하여 선택하시면 좋을 것 같습니다.
